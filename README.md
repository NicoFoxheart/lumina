# LUMINA ✨

**Light in darkness**

An interactive experience about pain, beauty, and the courage to keep going.

## About

Lumina is a web-based visualizer that explores the coexistence of pain and beauty. Through interaction, users transform tears into stars, discovering that broken things can still glow from within.

## Experience

- Move your mouse/finger to create light
- Click/tap to create bursts of stars
- Watch tears transform into light
- Read messages of hope and resilience

## For

- Everyone who's hurting but still here
- Everyone who's broken but still beautiful  
- Everyone who needs to hear: don't give up

## Tech

Built with vanilla JavaScript, HTML5 Canvas, and love 💙
